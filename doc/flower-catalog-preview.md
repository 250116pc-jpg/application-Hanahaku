# 花画像のお試し図鑑

ホームの「図鑑」で、右上の「お試し表示：ON / OFF」を切り替えます。
ON は画像・詳細の確認専用で、契約や保存データを変更しません。
季節タブと「前へ / 次へ」で全件を確認できます。

asset_046.png〜069.png のうち、存在する19枚を追加しています。
不足：asset_058.png、059、066、067、068。追加後は flowerCatalog.ts の definitions に追記してください。
名前と季節は画像の見た目に合わせた仮設定で、実際の植物の同定結果ではありません。
能力・レア度・レベル・スキル・契約条件は未設定です。
既存16件を含め、図鑑の定義は35件です。

## 今後の契約処理との接続

花のIDは 1000 + 素材番号（例：asset_046.png → 1046）で固定しています。
正式な登録状態は Phaser registry の registeredCharacterIds（number[]）から読みます。
編成中のキャラクターやお試し表示のON/OFFから正式登録を推測しません。
契約処理・DB保存・ログイン時の復元は未実装です。今後、ユーザー別に保存した
契約済みIDを読み込み、このキーに設定してください。攻略しただけでは登録せず、
契約成功を保存してから一覧を更新する想定です。
キー未設定時は正式登録0件です。お試し表示は初期状態でONです。

```ts
scene.registry.set('registeredCharacterIds', contractedCharacterIds)
```
