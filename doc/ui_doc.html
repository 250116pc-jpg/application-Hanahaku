ui.ts モジュール仕様書

src/utils/ui.ts は、プロジェクト全体の共通UIコンポーネント（テキストスタイル、各種ボタン、汎用ダイアログ）を提供するユーティリティモジュールです。画面ごとのUI実装の重複を減らし、デザインの統一とメンテナンス性の向上を目的としています。

共有用メモ: このドキュメントはブラウザで直接閲覧できるほか、ブラウザの「印刷機能（Ctrl+P / Cmd+P）」を使ってそのままPDFとして保存することもできます。

1. 定数・共通スタイル

FONT_FAMILY

プロジェクト統一のフォントファミリー定義です。

  • 値: '"Yu Gothic", "Meiryo", sans-serif'

getTextStyle(fontSize, extraOptions)

標準的なテキストスタイルオブジェクトを生成して返します。

  • 引数:
    • fontSize (number): フォントサイズ (px)
    • extraOptions (object, 任意): 追加・上書きしたい TextStyle オプション
  • 戻り値: Phaser.Types.GameObjects.Text.TextStyle

2. コンポーネント生成関数

createTextButton(scene, x, y, label, onClick, options)

テキストベースのシンプルなUIボタン（戻るボタン、タブ、HUDボタンなど）を生成します。ホバー・クリック時の背景色変化アニメーションを自動処理します。

  • 引数:
    • scene (Phaser.Scene): 描画先のシーン
    • x, y (number): 表示座標
    • label (string): ボタンのテキスト
    • onClick (() => void): クリック時の実行処理
    • options (object, 任意): fontSize, bgColor, hoverColor, downColor, padding など
  • 戻り値: Phaser.GameObjects.Text

createRectButton(scene, x, y, width, height, label, onClick, options)

枠線付きの矩形ボタン（ポップアップ内ボタンや大型アクションボタンなど）を Container 化して生成します。

  • 引数:
    • scene (Phaser.Scene): 描画先のシーン
    • x, y (number): 表示座標
    • width, height (number): ボタンの幅と高さ
    • label (string): ボタンのテキスト
    • onClick (() => void): クリック時の実行処理
    • options (object, 任意): fontSize, fillColor, hoverColor, downColor
  • 戻り値: Phaser.GameObjects.Container

3. 汎用ダイアログ

showRetreatDialog(scene, onRetreat) Depth: 4000

ステージ脱出・撤退時に表示する最前面モーダルダイアログ（暗転背景＋確認ポップアップ）を生成・表示します。「キャンセル」選択時は自動でコンテナが破棄されます。

  • 引数:
    • scene (Phaser.Scene): 描画先のシーン
    • onRetreat (() => void): 「撤退する」を押した時の処理（シーン遷移など）
  • 戻り値: Phaser.GameObjects.Container

4. 実装例

import { getTextStyle, createTextButton, showRetreatDialog } from '../utils/ui';

// 1. テキストスタイルの取得
const titleText = this.add.text(100, 50, 'タイトル', getTextStyle(32));

// 2. HUD用ボタンの作成 (深度調整をする場合)
createTextButton(this, 100, 100, 'バッグ', () => this.openInventory(), { fontSize: 22 })
  .setDepth(2000);

// 3. 撤退ポップアップの呼び出し
createTextButton(this, 700, 100, '撤退', () => {
  showRetreatDialog(this, () => this.scene.start('SelectStageScene'));
});
