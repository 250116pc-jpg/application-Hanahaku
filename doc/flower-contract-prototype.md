# 花契プロトタイプ（Saito）

`npm run dev` を起動し、ホームの「図鑑」を開きます。
開発中だけ `/?flower-test=1` で図鑑を直接開けます。

1. 春・夏・秋・冬を切り替え、ページ送りで35種類の花を確認。
2. 未契約の花の「詳細」を開く。花契前は編成不可。
3. 「花契する（テスト）」で花のカラー画像と編成ボタンが表示。
4. 「この花を編成する」→「キャラ詳細」で編成した花とATKボーナスを確認。
5. 花詳細から編成解除可能。「テストを初期化」は確認画面を挟んで初期化。

花契状態・編成はメモリ内の試作データです。ホーム往復では保持し、ページ再読み込みで初期化します。本番のユーザー所持情報・編成・DBには保存しません。能力値と季節は試作用。花本体にHPはなく、詳細のHPはプレイヤーのものです。

画像は `src/assets/flowers`。DBの `Game_image` は同じ相対パスを保存します。Viteで表示する際はこのパスを画像importのURLへ解決する必要があります。現在の試作一覧はローカルカタログを使用し、DB読み取りAPIはまだ接続していません。
