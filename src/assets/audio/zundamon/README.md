# 設定画面の音声

音声：VOICEVOX:ずんだもん（あまあま）
VOICEVOX ENGINE 0.25.2 / speaker style ID 1
速度 1.05、24kHz、モノラル。2026-10-01生成。

利用時は「VOICEVOX:ずんだもん」のクレジット表記を維持してください。
この音声を再利用・配布する場合も、以下の利用規約を遵守し、再利用者にも遵守を求めてください。
- https://voicevox.hiroshiba.jp/term/
- https://zunko.jp/con_ongen_kiyaku.html

ゲームにはWAVを同梱し、プレイヤー側にVOICEVOXは不要です。
音声音量（既定100%）とミュートに連動します。SE音量とは独立し、ミュート中・音声音量0のときは読み上げません。
音声素材はピーク約-1dBFSへ正規化しています。発話中はBGMの再生音量を設定値の15%にし、終了・中断・画面退出時に戻します。BGMの設定値は変更しません。
muted.wavも収録していますが、ミュート操作時は音を出さず文字のみ表示します。
