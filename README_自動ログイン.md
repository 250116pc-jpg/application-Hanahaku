# 30日間の自動ログイン

初回にメールまたはGoogleでログインすると30日間有効なCookieを発行します。
起動時にPHPが検証し、有効ならホームへ移動します。期限はアクセスで延長しません。
設定画面のログアウトで、このブラウザのトークンをDBから削除します。
Cookie削除や期限切れの場合は通常のログインが必要です。

## セットアップ
- PHPと画面は同じサイトで運用してください（localhostのポート違いは対応）。
- .envのVITE_PHP_BASE_URLを各自のPHP配置先に設定してください。
- アプリのDBで sql/auth_sessions.sql を一度実行してください。既存usersは変更しません。
- 本番はHTTPSを使用してください。HTTPSではSecure Cookieになります。
- CookieはHttpOnly / SameSite=Lax、DBには256bitランダムトークンのSHA-256のみ保存します。
- localStorageは表示用です。今後の保護APIでも必ずサーバー側でセッションを検証してください。

## 手動確認
1. メール/Googleでログインし、再読み込みでホームに入れること。
2. ブラウザを閉じて開き直してもログインが維持されること。
3. 設定からログアウトし、再読み込みで自動ログインされないこと。
4. Cookie削除後、ログイン画面へ進めること。
5. PHP停止時も起動時の確認は8秒以内に終了し、タイトル操作が可能なこと。
