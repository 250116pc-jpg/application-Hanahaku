# 管理者ツール

## 利用範囲

この管理画面は開発・テスト用です。ログインやパスワードは不要ですが、管理APIは同じPCの `localhost`（IPv4/IPv6 loopback）からの接続だけを許可します。各メンバーが自分のPCで起動して使ってください。

別PCからのアクセス、LAN共有、ポートフォワーディング経由では管理APIを利用できません。外部から使えるように公開しないでください。リモート共有が必要になった場合は、管理者認証を有効にする構成が必要です。

## 開き方

通常のローカル開発では、各メンバーが自分のPCで次の手順を行います。

1. XAMPP Control PanelでApacheとMySQLを起動します。
2. リポジトリのルートで `npm run dev` を実行します。
3. `http://localhost:5173/admin/` を開きます。

ApacheはPHP API、MySQLはDB、Viteは管理画面の表示を担当します。Apacheだけでは画面を表示できません。各PCの `.env` には、そのPCのDB接続情報とApache上のPHP APIを指す `VITE_PHP_BASE_URL` が必要です。ゲームへのログインは不要です。

## 操作

- 名前・メールアドレス・IDでユーザーを絞り込めます。
- アカウントを選ぶと、コイン・全アイテム・所持花の育成状況・ステージ進行状況が一覧で表示されます。
- コインは±100、アイテム数と花／スキルレベルは±1で調整できます。数値を直接入力することもできます。数値変更は「変更を保存」ですぐにまとめて反映します。花レベルに対応するEXPはサーバー側で既存の育成ルールから計算します。
- アイテムと所持花は「データを追加」欄から追加できます。アイテムは指定数を加算し、同じ花がすでに登録されている場合は重複しません。
- クリア済みのステージを個別にリセットできます。コインは減りませんが、再クリア時には通常のクリア報酬を再度獲得できます。
- 「主人公の切り替え」から男主人公または女主人公を選びます。設定はユーザーごとではなくゲーム全体に共通し、ゲームを再読み込みすると反映されます。
- DB更新前の確認ダイアログは表示されません。未保存の変更がある状態でアカウントを切り替えると、その変更は破棄されます。
- 操作履歴には直近100件の成功した変更について、共通管理者・対象ユーザー・日時・変更前後の値が記録されます。履歴の記録はデータ更新と同じDBトランザクションで行います。

画面はこのフォルダー、管理APIは `php/admin/manage.php` にあります。主人公の選択は `php/admin/player-character.json` にゲーム全体の設定としてローカル保存され、Gitには含まれません。ゲーム側は読み取り専用の `php/player-character.php` から設定を取得します。主人公の切り替えにDBの追加テーブルは不要です。花の育成データには `player_flowers` と育成カラムが必要です。

初回は `sql/admin_audit_log.sql` をDBに適用してください。未適用の場合は履歴が読めず、変更操作も履歴記録と一緒にロールバックされます。
