敵データ
ステージ JSON の enemies には enemy ID と出現座標を記述します。
ステータスは enemy{ID}.json（例: enemy1.json）に記述します。
stage/data.php が出現座標とステータスをまとめてゲームへ返します。
maxHealth / attackDamage / attackRange / attackVerticalRange / attackReachPadding / aggroRange / aggroVerticalRange は戦闘値、patrolDistance / patrolSpeed / chaseSpeed は移動値です。
attackIntervalMs / attackWindupMs は攻撃間隔と攻撃発生までの時間です。
hitbox と visual には物理判定・表示スケール・HPバー位置を設定します。
