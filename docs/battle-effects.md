# 戦闘演出の更新（2026-11-06）

## 見た目

- オリジナルの森の遺跡背景 `sanctuary-twilight.png`。背景は地形の80%の速度でスクロールし、遠景に奥行きを持たせる。
- 暖色のランタン、寒色の霧、木漏れ日、漂う光、実際の地形を追う足元の影。HUDにはビネットを重ねない。
- 炎の斬撃、太陽光線、水の波、追尾弾、結界、回復などの演出を `SkillEffects.ts` に分離。既存スプライトのハイライトを保持。
- 発動名、実ダメージと実回復量の数字、既存のSE音量／ミュートに従う短い合成効果音を追加。
- OSの「視差効果を減らす」設定ではカメラ揺れを停止し、スキルの粒子数を減らす。

## 動作

- 160msの予備動作後に効果が発生。連撃・紅葉の各段階は、命中と同じタイミングで描画する。
- 溜め中は移動・方向転換・ジャンプ・通常攻撃を制限。追尾弾は220msの飛行後に命中する。
- 補助効果はプレイヤーに追従し、期限・死亡・シーン終了で片付ける。同じオーラの再発動は置き換える。
- 戦闘用の経過時間を一元化。ポーズ中はMP再使用待ち・バフ・敵の待ち時間が進まない。
- MP不足通知を保持し、読み込み失敗を通常のスキル名で上書きしない。
- 敵への弱化を味方の状態欄に表示しない。紅葉の赤形態で緑形態の補助表示を再付与しない。
- 初期化リクエストがシーン終了後に完了しても古いHUDを更新しない。

## 開発プレビュー

`npm run dev` を実行して `http://localhost:5173/?battle-preview=1` を開く。

- 上部の10個のボタン、または数字キー `1`〜`9`・`0` で全スキルを試せる。上部ボタンはMPとクールダウンの検証用ではなく、演出を繰り返し見るためのもの。
- `R` でステージをリセット。紅葉は2回使用すると緑→赤の順に変化する。
- 下部の編成カードは通常どおりMP・クールダウンを消費する。
- スキル定義は既存の `php/skill/skills.json` を読み、PHPと同じレベル計算で初期状態を作る。ログイン不要。敵データの取得には既存のPHPサーバーが必要。
- プレビューでは勝敗からの戦績保存と救出・契約への遷移を止め、バッグを開かない。
- この入口は `import.meta.env.DEV` で制限される。本番のログイン・DB認証の省略処理ではない。

## 素材

`sanctuary-twilight.png` は今回 imagegen で制作したオリジナル背景。既存ゲームから抽出した素材は使用していない。光や粒子は実行時生成、スキルスプライトと地形はプロジェクトの既存素材を使用。

参考にした表現の方向性：[スクウェア・エニックス公式 HD-2D 紹介](https://www.jp.square-enix.com/octopathtraveler/about/)。この実装は既存のPhaser 2D描画を使うもので、3Dエンジンへの変更ではない。

## 検証

Chromeの実画面で全10スキルの発動とMP消費、紅葉の赤形態3段攻撃、左右反転、溜め中の操作制限、ポーズ復帰、連打、オーラ追従、死亡時消去を確認。
連撃終了後のオブジェクト数とpostupdateリスナー数が開始前に戻ることも確認。TypeScriptとViteの本番ビルドで確認する。
