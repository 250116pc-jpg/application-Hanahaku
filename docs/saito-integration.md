# Saitoの図鑑・花データ取り込み

花IDとskill_idの対応は、1ジニア、2スイレン、3ひまわり、4サルスベリ、5ムクゲ、6コキア、7ハス、8ルリマツリ、9アジサイ、10ハンゲショウです。
個別JSON、編成、ステージ画像、スキル定義、SQLの対応を検証しています。
mainの最新のPlayer.tsとskills.jsonの戦闘修正は維持しています。

## 既存保存データ
ブラウザの編成v1は花の名前を維持する新IDへ移行します。旧桜(ID3)の枠は空欄になります。新規保存はv2です。
DBの契約・スキル状態は自動移行しません。旧IDで保存されたDBにseedをそのまま適用すると所持する花の意味が変わるため、バックアップの上、担当者が対応を確認してください。

## DBと検証範囲
この取り込みではDBを変更していません。2026-10-27のローカルDB確認ではhanahaku.flowersが存在せず、DB接続を含む戦闘の実機動作は未検証です。
sql/skill_seed.sqlはテーブル作成の前提があり、末尾に全ユーザーへ花1〜10を契約済みとして追加する処理を含みます。通常運用で無条件に実行しないでください。
図鑑の花契テストはメモリ内のみで、DB契約には接続していません。

型チェック・Viteビルド、35個の図鑑IDの重複、10個の個別JSON/編成/スキル/SQL対応、画像参照、編成v1移行と保存再読込、PHP構文を検証済みです。
.envはmainの内容を維持しています。
